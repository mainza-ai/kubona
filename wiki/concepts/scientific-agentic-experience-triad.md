# The Scientific Agentic Experience (AX) Triad

The user experience and multi-agent interaction model defining how human researchers steer autonomous swarms, how specialized agents deliberate through formal protocols, and how the platform projects dynamic generative interfaces.

### Axis A: User ↔ Agent Interaction (Human-Machine Steering)
- **Strategic Intent Declaration:** Humans declare boundary conditions, spending ceilings, and verification mandates rather than micro-prompting individual gate angles.
- **Calibrated Friction:** Routine steps (literature retrieval, classical DFT baselines, syntax checks) proceed with zero friction. Irreversible or high-cost actions (QPU hardware dispatch, ledger commits) require explicit **WebCrypto Ed25519 biometric signatures** on cryptographic gate cards. See [[spend-mandates-and-delegation|AP2 Spend Mandates]].
- **Flight Recorder Scrubbing:** Researchers can scrub through multi-hour reasoning traces, inspecting cavity expansions and branch prunings.
- **Counterfactual Branch Forking:** Users can fork execution at any historical checkpoint to test alternative hypotheses in parallel.

### Axis B: Agent ↔ Agent Interaction (The Epistemic Tribunal)
Deliberation is governed by formal verification rather than unstructured natural-language chat:
- **Specialized Personas:** `lead_theorist`, `lean4_proof_engineer`, `classical_anchor_solver`, `quantum_circuit_compiler`, `adversarial_falsification_critic`, `sentinel_spend_governor`, `multimodal_spectroscopist`. See [[multimodal-mission-control-and-custom-agents]].
- **Tribunal Protocol:** Proposal submission $\to$ Adversarial challenge $\to$ Formal verification $\to$ Analytical anchor audit $\to$ Quorum voting. Discoveries are committed to the ledger only upon supermajority consensus.
- **Shared Merkle Blackboard:** Eliminates context flooding by storing large tensors, Hamiltonians, and proofs as immutable content-addressed references.

### Axis C: Agent ↔ Interface Interaction (A2UI Generative Scientific UI)
Agents dynamically stream typed React/WebGL widgets directly into the workspace:
1. `molecular_active_space_3d`: Mol* 3D active space orbital inspector.
2. `quantum_circuit_qir_editor`: Interactive post-QIR schematic with Clifford+$T$ overlays.
3. `lean4_goal_tree_inspector`: Interactive proof tree with active goals and remaining cavities.
4. `shadow_tomography_radar`: 3D Bloch sphere projections with randomized Clifford convergence bounds.
5. `epistemic_manifold_surface`: WebGL terrain mapping Fisher–Rao curvature and belief states.

## 2. The Nine Observatory Surfaces of the Cognitive Cockpit

1. **Surface 1: Spatial Research Canvas:** Infinite zoomable research graph from macro-campaigns to micro-atomic lattices with live agent presence.
2. **Surface 2: 4D Flight Recorder & Cognitive Timeline:** Scrubbable timeline displaying cognitive shifts, cavity expansions, and branch forks.
3. **Surface 3: Epistemic Manifold & Analytical Anchors:** 3D Riemannian Fisher–Rao belief landscape rendering epistemic curvature $R_{\mu\nu}$.
4. **Surface 4: Autonomy Cockpit & Calibrated Friction Cards:** Real-time burn-rate monitoring and Ed25519 action gate cards.
5. **Surface 5: Execution Tier & Hardware Fleet Radar:** Multi-modality hardware telemetry (neutral atoms, trapped ions, superconductors) with queue depths and export-control shields.
6. **Surface 6: Cognitive LLM Mesh & Sovereign Control Deck:** Port-level local model radar, air-gap toggle, and custom agent builder.
7. **Surface 7: Citable Results Studio & Systematic Notebook:** Structured auto-generated manuscripts with frame-anchored human annotations.
8. **Surface 8: Epistemic Tribunal Room & Swarm Deliberation:** Multi-agent debate chamber with quorum consensus voting.
9. **Surface 9: Generative Scientific UI (A2UI Surface):** Dynamic runtime embedding interactive scientific widgets into user workflows.
