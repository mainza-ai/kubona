# World Labs Atlas / Marble 2

**Live URL:** https://www.worldlabs.ai · https://atlas-beta.worldlabs.ai  
**Integration Class:** **Sidecar** ([[integration-topology-and-licence-discipline]]).  
**API Surface:** Marble 2 Developer API (`api.atlas-beta.worldlabs.ai/api/v2`).  
**Prior-Art Tooling:** `worldlabsai/atlas-camera-studio` (MIT License, camera-path spline editor).

World Labs develops spatial intelligence world models capable of estimating 3D cameras, generating novel perspective views from depth conditioning, and reconstructing environments. In Kubona, Atlas serves as an **optional, cloud-connected generative lens (Tier 2)** for the [[observatory-spatial-representation-layer]], operating behind the [[integration-topology-and-licence-discipline|Sidecar pattern]].

## API Architecture & Beta Endpoints

The Marble 2 Beta Developer API is asynchronous and task-based. Operations return long-running operation envelopes (`GET /api/v2/operations/{id}`) with support for signed webhooks.

> ⚑ Correction (2026-10-23, settled by [[observatory-lens-audit-2026-10-23]] /
> [[source-world-labs-atlas-2026]]): webhook verification is **Ed25519 `v1a`
> Standard Webhooks** (JWKS at `/.well-known/webhooks/jwks.json`) — there is
> no HMAC, and no `WLT-Signature` header exists in the live contract.

| Task Route | Method | Purpose in Kubona |
|---|---|---|
| `/api/v2/tasks:atlasChisel` | Depth-guided generation | Generates posed RGB views at 1280 × 720 from 1 to 32 target cameras, conditioned on Kubona's planar depth layouts (`depth.depthAsset` EXR or `depth.logDepthAsset` PNG), a style prompt, and optional `voxelSize` (0 to 0.4). |
| `/api/v2/tasks:atlasGenerate` | Posed RGBD generation | Generates novel views from RGBD context frames; `returnDepth: true` reconstructs output depth via multi-view stereo (returns `NaN` in unobserved regions). |
| `/api/v2/tasks:images2PosedRGBD` | Camera & depth estimation | Estimates pinhole intrinsics and camera-to-world extrinsics from one or more unposed photographs (gravity-leveled, 1280 × 720 target grid). |
| `/api/v2/tasks:atlasMasked` | Multi-view inpainting | Preview task completing masked regions across 1 to 16 views using 8-bit grayscale PNG keep-masks. |
| `/api/v2/tasks:splats2Mesh` | Splats to Mesh | Converts `.spz` Gaussian splat scenes into textured meshes (`.glb` / OBJ) with UV atlases up to 8192 × 8192. |

## Camera & Depth Coordinate Conventions

1. **Extrinsics:** Camera-to-world unit quaternions in **XYZW** order, position in world coordinates $[x, y, z]$. Coordinate systems supported:
   * `"rub"`: Right, Up, Back (looking along local $-Z$; matches Three.js, OpenGL, and Blender camera axes). This is Kubona's normalized internal convention.
   * `"rdf"`: Right, Down, Forward (looking along local $+Z$; OpenCV standard).
2. **Intrinsics:** Absolute pixel pinhole parameters: $f_x, f_y, c_x, c_y, width, height$. The generation grid defaults strictly to **1280 × 720**.
3. **Planar Depth:** Optical axis view-space $z$-depth (not ray distance). Voids and sky must be explicitly marked as `0` (or `NaN` / infinity in EXR).

## Governance, Data Sovereignty & Terms of Service

* **Sidecar Rule:** Atlas is never on the correctness path. Kubona's [[observatory-spatial-representation-layer]] operates a deterministic, 100% local Three.js WebGL canvas (Tier 1) at $0.00 cost with zero network egress. Atlas is reached only when the user explicitly requests an illustrative lens view.
* **Sovereign Air-Gap Invariant:** When `air_gapped: true`, all outbound calls to `api.atlas-beta.worldlabs.ai` are strictly refused by the Go proxy.

> ⚑ Correction (2026-10-23, settled by [[observatory-lens-audit-2026-10-23]]):
> the refusal surfaces as error code `forbidden` ("Sovereign Air-Gap active:
> external cloud generative synthesis refused") — no `AirGapEnforcedError`
> type exists in the codebase.
* **Asset Retention Modes:**
  * `dev_inspect`: Retains uploaded depth assets in the project library for debugging camera alignments and EXR encodings during beta development.
  * `ephemeral_purge`: Issues `DELETE /api/v2/assets/{id}` immediately upon view retrieval to prevent cloud persistence of proprietary laboratory geometries.
* **Truth Contract:** Model-generated outputs are stamped with `[ILLUSTRATIVE_SKIN · ATLAS CHISEL]`. Pixels generated by Atlas never carry scientific claims, values, or labels; all data floats on ledger-anchored SVG plaques.
