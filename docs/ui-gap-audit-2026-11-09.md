in the 2026-11-09 program. This is a UI/capability wiring audit, not a visual
redesign. Contract evidence is generated by
`scripts/console-contract-inventory.py` and `scripts/console-openapi.mjs`.

## Remaining UI gaps (ordered)

1. **Vendor cost preview is not available.** The panel now says so explicitly
   and keeps the signed operator cap; a priced preview requires a reviewed
   vendor rate-card integration, not a guessed per-shot number.
2. **Manuscript/report generation is still chemistry-primary.** The generic
   experiment report/export covers spin/excited/reaction/conjecture records,
   but the paper template and abstract remain molecular-VQE-shaped.
3. **Manual VoiceOver/NVDA remains human-only.** Automated axe, keyboard,
   reduced-motion, forced-colors, and 200% zoom checks remain green; no human
   screen-reader pass has been recorded for the new panels.
4. **Hardware cost/settlement history is not a dedicated UI surface.** Job and
   ledger records carry usage/actual USD; the launch panel is not an accounting
   dashboard.
