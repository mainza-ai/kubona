## Remaining UI gaps (ordered)

1. **Protocol history is ephemeral.** `DiscoveryProtocolPanel` shows the latest
   protocol response but does not list prior protocol ids or re-open their
   reports. The ledger has the events; the UI needs a history projection.
2. **Campaign report/archive is chemistry-shaped.** ResultsStudio renders the
   new typed experiments, but the manuscript/report generator still assumes a
   molecular VQE/PES primary measurement. A science-report template should
   include spin/excited/reaction/conjecture sections when those are the primary
   records.
3. **No cost preview in hardware launch.** The panel accepts an operator max
   budget but does not show a vendor price estimate before signing. The parent
   rail still enforces mandate/fidelity/settlement; the UI should display a
   priced estimate or explicitly say the operator must set the cap.
4. **Manual VoiceOver/NVDA remains human-only.** Automated axe, keyboard,
   reduced-motion, forced-colors, and 200% zoom checks remain green; no human
   screen-reader pass has been recorded for the new panels.
